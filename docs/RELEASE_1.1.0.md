## Перенос на сайт

Новые 100 вариантов заполняют всю поверхность. Только проверяемые периодические поля помечены repeat; растры и композиционные CSS — cover. Цвета SVG/CSS следуют существующим переменным сайта; полноцветные WebP сохраняют исходную палитру. Неон у 16 прежних карточек остаётся отдельной выключенной опцией.

Экспорт не содержит JS и сторонних библиотек. На сайт переносится один рецепт и его зависимости. Размеры — COLLECTION_METRICS_1.1.0.json и RASTER_METRICS_1.1.0.json, происхождение — ASSET_ORIGINS.md. Каталог для выбора содержит все превью и не предназначен для подключения к клиентскому сайту.

Проверки и их пределы — QA.md. Настоящая браузерная проверка галереи и производительность на телефоне не заявляются.
