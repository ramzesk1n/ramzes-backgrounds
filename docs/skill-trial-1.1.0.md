# Независимое применение skill · 1.1.0

Свежему агенту переданы путь установленного skill и обычная локальная задача: ровный латте без чашки и рисунка, тонкая связанная паутинка на всю вторую секцию, действующая палитра CSS и обе темы. Ожидаемые ID и техническое решение не передавались.

Агент выбрал latte-uniform-photo и cobweb-fine-sheet. Цвета сохранены как живые ссылки на --page, --secondary, --brand и другие переменные theme.css. Использованы отдельные rb-latte и rb-cobweb, JS не добавлен. Латте: интенсивность 0.56 в светлой теме и 0.18 в тёмной; паутинка: 0.28, период 320 px.

Агент проверил пути, обе палитры, повторение SVG 3×3/5×5, хеши и доступный расчёт контраста. Основная сессия повторно проверила HTML-ссылки, отсутствие script и все хеши экспортов. Браузерная проверка вёрстки и тем не выполнена.

Пример перенесён в examples/latte-cobweb/. Масштаб и интенсивность демонстрационные; их следует проверять на реальном сайте. Производные: латте 116 618 Б, mobile 43 782 Б; SVG-паутинка 12 540 Б. Взвешивать CSS и реальные выбранные зависимости, а не PNG-мастера или весь каталог.
