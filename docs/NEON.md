# Неоновый режим

Неон — отдельный статичный ореол у 16 подходящих рецептов. Он не входит в обычный экспорт. Галерея: включить «Только карточки с неоном», затем «Неоновый ореол». Выбрать роль цвета или свой HEX, роль ядра SVG и яркость. Для яркого ореола обычно нужен контрастный background сайта; палитра не переключается в тёмную автоматически. Копирование CSS и скачивание HTML учитывают неон.

## CLI

```bash
python3 scripts/backgrounds.py list --neon
python3 scripts/backgrounds.py export branch-lightning --out /absolute/project/backgrounds/lightning --tokens /absolute/project/design-system/background-tokens.json --neon --neon-intensity 0.6
python3 scripts/backgrounds.py export soap-bubbles --out /absolute/project/backgrounds/bubbles --tokens /absolute/project/design-system/background-tokens.json --neon --neon-color-role secondary --neon-core-role highlight
```

По умолчанию ореол следует accent, ядро SVG — highlight. `--neon-color-role`/`--neon-core-role` сохраняют var()-связь с реальными bindings сайта. `--neon-color '#55ccff'` и `--neon-core '#ffffff'` намеренно фиксируют выбранный цвет; не сочетать фиксированный цвет с ролью того же слота. Неоновому режиму нужен --neon; неподдерживаемые карточки отклоняются до создания папки. Все параметры отражаются в lock.

| CSS-переменная | Значение по умолчанию | Назначение |
|---|---|---|
| --rb-neon-color | accent сайта | Цвет ореола |
| --rb-neon-core | highlight сайта | Цвет ядра SVG; не применяется к многоцветному CSS-ядру |
| --rb-neon-intensity | 0.55 | Альфа ореола, 0–1 |
| --rb-intensity | Значение карточки | Альфа основного рисунка |

У CSS-вариантов основной цветовой рисунок управляется обычными primary/secondary/accent/highlight; неоновый слой добавляет ещё одно мягкое поле. У SVG цвет основного рисунка в неоновом режиме заменяется светлым ядром. Выключение режима возвращает обычный ink. При нулевой яркости выключается только ореол; для полного возврата к обычному рисунку отключить режим.

## Внедрение

Обычный слой занимает ::before, неон — ::after. Проверить оба псевдоэлемента в проекте. Для нескольких рецептов переименовать .rb-surface во всех селекторах. Готовый SVG-ореол использует более широкие полупрозрачные штрихи, CSS — градиенты. Нет SVG-фильтров, filter/drop-shadow/backdrop-filter, Canvas/WebGL, анимаций и клиентского JS. Цена покраски остаётся: проверять большую площадь на целевом устройстве. Не обещать физическое свечение или нулевую нагрузку.

Ореол и ядро проверены через растеризацию SVG; CSS-композиции и управление в браузере требуют отдельной визуальной проверки.
