# Независимое применение skill · 0.4.0

Свежему агенту передан существующий мини-сайт производителя фотонных сенсоров, светлая/тёмная тема и путь skill. Дана задача подобрать и внедрить лёгкую подложку без клиентского JS, с автоматическим наследованием цветов. Ожидаемый ID не сообщался.

Агент выбрал halo-rings, связал десять семантических ролей с уже имеющимися --photon-* и подключил только background.css. Сохранены текст и theme.css, тема примера не подключена к странице. Интенсивность снижена до 0.18 и 0.16 на узком экране. Никаких ассетов, JS или фильтров.

Размер внедрённого CSS с привязками: 1079 Б, gzip 516 Б. Это отличается от размера базового рецепта в каталоге: в экспорте добавлены живые CSS-алиасы.

Основной агент отдельно сверил пути, var()-привязки, отсутствие JS и все хеши lock. Автоматическая смена цвета следует из CSS-наследования; браузерное переключение тем, вид градиента и переполнение не проверены.
