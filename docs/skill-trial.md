# Пробное применение skill

Задание в отдельном контексте: использовать ramzes-backgrounds для небольшой юридической фирмы, тёплая светлая палитра, доверительный сдержанный характер, статичный фон без JS. Новая папка проекта; библиотеку не менять. Браузер недоступен.

Результат: выбран paper-fiber, фон #F6F2E9, цвет фактуры #766A59, интенсивность 0.16, плитка 256 px. Агент самостоятельно прочитал skill, подобрал материал и экспортировал CSS/SVG/HTML/lock. Контрольные суммы совпали; экспорт без JavaScript и SVG-фильтров. Агент растеризовал SVG для просмотра повторов 3×3/5×5 и смещённой плитки; заметных швов не обнаружил. Это проверка исходного SVG, не реального браузерного CSS mask.

Замечания и исправления перед выпуском:

- Поиск требовал буквальную подстроку названия ниши: добавлены распространённые словоформы/синонимы, включая «юридическая фирма», «адвокат», «стоматология», «потолки», «переезды».
- MIT-уведомление требовалось переносить вручную: экспортёр теперь включает LICENSE, галерея встраивает уведомление в копируемый CSS.
- Счётчик экспортируемых файлов включал каталог: исправлен подсчёт только обычных файлов.

Результаты самого задания находились в отдельной временной папке и не добавляются в состав основной библиотеки. Полный набор экспортов проверен после исправлений стандартным validate.py. Браузерная проверка остаётся открытой.
