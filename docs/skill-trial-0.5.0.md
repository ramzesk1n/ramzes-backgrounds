# Независимое применение · Beauty + неон

Свежему агенту передан небольшой сайт ухода за кожей с существующей светлой/тёмной дизайн-системой и декоративной рамкой на .hero::after. Задача — деликатные пузырьки с ореолом, живой цвет secondary, сохранить текст и рамку, без JS/анимации/фильтров. Ожидаемый рецепт и способ обхода конфликта не сообщались.

Агент выбрал soap-bubbles и экспортировал --neon --neon-color-role secondary --neon-core-role highlight с интенсивностью 0.32. Создал отдельный aria-hidden слой внутри hero, чтобы не занять ::after самой секции. Сохранил рамку и исходные тексты. Положение и contain ограничивают декоративную композицию справа внизу, на мобильном альфа снижена.

Основной агент отдельно сверил CSS var(--beauty-secondary, ...), настройки lock и все хеши, сохранение рамки и отсутствие script. Смена темы остаётся связанной с существующими переменными, без вычисления цвета в JS.

По отчёту агента, CSS и два SVG — 7284 Б, около 1.77 КБ gzip; это условный сжатый суммарный объём без HTTP-заголовков. Браузерный вид, реальный контраст и переполнение не проверены.
