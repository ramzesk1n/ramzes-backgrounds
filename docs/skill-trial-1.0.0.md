# Независимое применение skill · 1.0.0

Свежему агенту передан только путь к обновлённому skill и обычная задача доработки сайта: сплошные мазки в beauty, поле пузырьков шампанского в wine, существующая палитра CSS и сохранение оформления. Диагнозы и ожидаемые технические решения не передавались.

Агент выбрал brush-paint (28%, 440 px) и champagne-effervescence (14%, 320 px). Прочитал дизайн-систему, создал tokens/bindings и сохранил живые var(). Основные псевдоэлементы обеих секций заняты номерами и рамками; агент внедрил отдельные aria-hidden слои с уникальными селекторами. JS не добавлен. Исходный styles.css сохранён без изменений.

Проверка результата: файлы существуют, ссылки на SVG разрешаются, палитра связана с существующими переменными, номера и рамки сохранены в CSS, фоновые классы не конфликтуют. Хеши lock-файлов после адаптации совпадают. Агент проверил повтор и контраст доступными средствами. Браузерный вид и смена темы в браузере не проверены.

CSS+SVG двух рецептов: 28366 Б; сумма gzip файлов: 5033 Б. Это размер зависимостей примера, не всего каталога и не гарантия сетевой передачи без настройки сервера.

Пример включён в examples/beauty-champagne/index.html. Полезен как образец внедрения при занятых ::before/::after; его палитра демонстрационная.
