# Ramzes Backgrounds · 1.1.0

В Git-версии сначала выполни `python3 scripts/build_gallery.py`, затем открой созданный `index.html`. Установке skill и экспорту эта сборка не нужна. PNG-мастера находятся в полном архиве; рабочие SVG/WebP входят в репозиторий.

Библиотека подложек для сайтов: 500 готовых статичных решений и 107 нишевых подборок, визуальный каталог, фильтры по нишам, палитры и экспорт только нужного материала. В готовой подложке нет клиентского JavaScript и сторонних библиотек.

## Начать

Открой `index.html` в браузере. Он самодостаточный, без CDN, шрифтов из сети и сервера. JavaScript используется только для работы каталога. При запрете локальных загрузок браузером открой папку через VS Code Live Server или `python3 -m http.server 8080`.

Включи «Новинки 1.1.0», чтобы увидеть ровно 100 новых карточек.

В галерее можно выбрать нишевую подборку, семейство, технологию, покрытие, стиль, эпоху и размещение, искать материал по названию, задать свои primary/secondary/accent и другие токены, импортировать JSON, изменить интенсивность и масштаб плитки, проверить повтор 3×3, скопировать CSS или скачать один готовый HTML-пример.

CSS в галерее содержит выбранные изображения как data URL для удобства переноса. Для реального сайта предпочтителен CLI-экспорт: отдельные изображения кешируются и не дублируются в стилях.

```bash
python3 scripts/backgrounds.py list --niche ремонт
python3 scripts/backgrounds.py list --seamless
python3 scripts/backgrounds.py export quiet-aurora --out /absolute/project/backgrounds/aurora --tokens /absolute/project/design-system/background-tokens.json
python3 scripts/backgrounds.py show microcement
python3 scripts/backgrounds.py export microcement --out /absolute/project/public/backgrounds/concrete --bg '#eee8dc' --ink '#665849' --intensity 0.4
```

Папка экспорта должна быть новой или пустой. Существующие файлы не перезаписываются. `background.css` и папка `assets` должны оставаться рядом; при переносе в Astro/Vite/другую сборку проверь итоговые URL. Подключи CSS и назначь секции класс `rb-surface`. Для нескольких разных подложек на странице переименуй класс каждого рецепта в уникальный, например `rb-concrete`, во всех его селекторах, включая медиазапросы. CSS рассчитан на декоративный псевдоэлемент `::before`: перед внедрением проверь, не занят ли он уже.

`background.lock.json` фиксирует версию, параметры и контрольные суммы. Обновление библиотеки не обновляет клиентский сайт автоматически.

## Подключить к агентам

```bash
python3 scripts/install_skill.py --target codex --project /absolute/project
python3 scripts/install_skill.py --target claude --project /absolute/project
```

Для личной установки вместо `--project` укажи `--user`. Существующий skill не перезаписывается. Codex: `$ramzes-backgrounds`; Claude Code: `/ramzes-backgrounds`. Данные и экспортёр входят в устанавливаемую папку: MCP и подключение к интернету для подбора не нужны.

## Проверка и сборка

```bash
python3 scripts/validate.py
python3 build.py
```

Пользованию и экспорту нужен только Python 3 со стандартной библиотекой. Пересборке и проверке растровых файлов нужен Pillow с WebP. Оригиналы для этой операции находятся в `masters/`. Генераторы SVG воспроизводимы, без SVG-фильтров; формат сборки — обычные файлы, npm не требуется.

Все 500 вариантов реализованы и проверяются структурно. Проверка во всех браузерах и измерение производительности на реальном клиентском сайте остаются отдельным этапом. См. `docs/QA.md` и `docs/SEAMLESS.md`.

## Живая палитра сайта

Цвета экспортируются как var(--переменная-сайта, запасной-цвет), поэтому смена токенов или темы сайта автоматически меняет подложку без JS и повторного экспорта. Укажи имена из своей дизайн-системы в bindings; пример — theme.example.json, инструкция — docs/TOKENS.md. theme-example.css подключается только в отдельном примере и не должен переопределять настоящие токены сайта. Явные --bg/--ink/--accent намеренно фиксируют соответствующий локальный цвет.
